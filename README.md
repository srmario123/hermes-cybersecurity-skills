# Hermes Cybersecurity Skills

Colección completa de skills de ciberseguridad para [Hermes Agent](https://github.com/NousResearch/hermes-agent).

## Contenido

Más de 800 skills organizadas por categoría, cubriendo:

- **Ofensiva**: red team, pentesting, exploits, C2, evasión
- **Defensiva**: detección, SIEM, EDR, hardening, zero trust
- **Forense**: memoria, disco, red, cloud, mobile
- **Threat Intelligence**: MITRE ATT&CK, IOCs, CTI
- **Cloud Security**: AWS, Azure, GCP
- **OT/ICS**: SCADA, Modbus, IEC 62443

## Uso

Copia el contenido en `~/.hermes/skills/cybersecurity/` o referencia las skills directamente.

## Mantenimiento

Este repositorio se actualiza automáticamente cada vez que se mejoran o agregan skills.
